## 🌾 Projeto em destaque: Grão

Um assistente financeiro conversacional. A pessoa escreve "Gastei 120 de luz" e o app registra o gasto, sem formulário.

- Um **LLM com function calling** transforma a frase em dados estruturados (tipo, valor, categoria) e consulta o banco por período e categoria, para responder com base nos dados registrados.
- Entrada por voz com a Web Speech API.
- Escrevi o PRD, com acessibilidade, LGPD e métricas de validação, e usei como contexto para gerar o código com o Lovable.
- Stack: React, TypeScript, Tailwind CSS, Shadcn UI e Supabase.

👉 [Ver o repositório](https://github.com/PedroHenrique158/grao-assistente-financeiro)
